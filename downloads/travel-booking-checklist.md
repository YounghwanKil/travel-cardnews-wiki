# 여행 결제 전 체크리스트

**표시가격보다 최종금액, 이동시간, 취소 조건을 먼저 확인하세요.**

여행 전 계산소 · 확인 기준일 2026-10-23

## 항공권

- [ ] 세금과 발권 수수료를 포함한 최종 결제금액을 확인했다.
- [ ] 위탁·기내 수하물 허용량과 추가요금을 확인했다.
- [ ] 항공사와 판매처의 취소·변경 수수료를 각각 확인했다.
- [ ] 주말·야간 취소 요청의 처리 기준일을 확인했다.
- [ ] 여권 영문명, 생년월일, 여권정보가 정확하다.
- [ ] 판매처와 운항 항공사 양쪽에 유효한 연락처가 등록돼 있다.

## 숙소

- [ ] 세금·리조트피·청소비를 포함한 최종금액을 확인했다.
- [ ] 무료취소 마감시각과 현지 시간대를 확인했다.
- [ ] 취소 시점별 실제 환불액을 확인했다.
- [ ] 공항·역·주요 일정까지의 교통비와 이동시간을 더했다.
- [ ] 늦은 체크인, 보증금, 체크인 신분증 조건을 확인했다.

## 공항·현지 교통

- [ ] 공항에서 최종 목적지까지의 총비용을 비교했다.
- [ ] 짐, 환승, 도보, 동행 인원까지 같은 범위로 비교했다.
- [ ] 심야 도착 시 실제 막차와 대체 교통비를 확인했다.
- [ ] 교통패스 가격과 실제 구간요금 합계를 비교했다.
- [ ] 패스 적용 범위에서 빠지는 노선을 확인했다.

## eSIM·로밍

- [ ] 기기의 실제 데이터 사용량과 측정 기간을 확인했다.
- [ ] 여행 일수와 직접 정한 여유분을 반영했다.
- [ ] 일일 제한과 제한 이후 속도를 확인했다.
- [ ] 테더링 허용 여부와 별도 한도를 확인했다.
- [ ] 유효기간 시작 시점과 개통·환불 조건을 확인했다.
- [ ] 기기의 eSIM 지원 여부와 통신사 잠금 상태를 확인했다.

## 보험·결제

- [ ] 필요한 담보가 실제 가입 항목에 포함돼 있다.
- [ ] 보상하지 않는 손해와 자기부담금을 확인했다.
- [ ] 물품별 하위한도와 실손·정액 지급 방식을 확인했다.
- [ ] 사고 현장에서 필요한 증빙과 청구기한을 저장했다.
- [ ] 해외 결제 화면의 현지통화와 원화 금액을 비교했다.
- [ ] 환율, 추가 수수료, DCC 마크업을 확인했다.

## 액티비티

- [ ] 정확한 무료취소 마감시각을 확인했다.
- [ ] 참가일·여행자 정보 변경 가능 여부를 확인했다.
- [ ] 최신 바우처의 집결지, 입구, 운영사 연락처를 저장했다.
- [ ] 노쇼 조건과 사전 도착 요구시간을 확인했다.
- [ ] QR, 신분증, 연령, 복장 등 참가 조건을 확인했다.

## 마지막 계산

- [ ] 모든 비용을 같은 통화와 같은 인원 기준으로 맞췄다.
- [ ] 추가 수하물·교통·수수료·예비비를 총액에 더했다.
- [ ] 결제 화면과 주요 약관을 캡처하거나 저장했다.
- [ ] 현재 가격과 정책을 공식 판매처에서 다시 확인했다.

이 체크리스트는 특정 상품 추천이나 법률·보험 자문이 아닙니다. 최신 조건은 결제 직전 공식 판매처와 실제 약관에서 확인하세요. 현재 제휴 링크가 없습니다.
